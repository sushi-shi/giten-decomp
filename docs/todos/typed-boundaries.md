# Typed layout and API boundaries

The remaining casts and partial layouts below need evidence before they can be
replaced. The exact functions that require a source-rule exception are listed
in [rule-exceptions.tsv](rule-exceptions.tsv). A matching score alone does not
prove that a proposed aggregate or signature is the original one.

| Boundary | Current example | Evidence needed for cleanup |
| --- | --- | --- |
| Field actor's original extent | `FieldActor` in `include/Game/FieldActor.h` embeds the 505-byte `CharacterCore` and the map state accessed through actor pointers. `Character` separately owns the complete roster record and its alignment histories; generic combat/script operations borrow `CharacterCore*`. | Copies establish the shared core, and map-pointer accesses establish a minimum actor extent through `hidden`. No standalone allocation or whole-actor copy proves the original map aggregate's complete extent or name. Preserve its identity marker until that witness is recovered. |
| Platform calls into game C | `src/Platform/winmain.cpp` casts `RedrawFieldAt` to a three-int function at the `AnimateMove` call, passes unsigned map dimensions through `GetMapSize`'s signed-word pointers in `BuildRoomGeometry`, and casts `SetMouseState` to a byte/LONG signature in `PollInput`. | Recover the declarations visible to the original Windows translation unit. The current C declarations and the retail push/sign-extension widths differ; retyping a C++ declaration or function-pointer call requires an ABI and mangling check. |
| Texture source argument | `OpenTextureBitmap` and `LoadTexture` take `const char* name` plus `fromFile`; in `src/Gfx/bitmapio.cpp` the false branch views `name` as a borrowed `BmpFile*`. `src/Gfx/layertexture.cpp` and `src/Gfx/objecttexture.c` pass bitmap data through that parameter. | Recover a typed overload or original heterogeneous API boundary while preserving the exact C/C++ symbol and call sites. A path and a bitmap pointer cannot be represented by one truthful `const char*` type without the selector. |
| Serialized area and object records | `DecodeAreaMap` in `src/Game/clock.c` rebases `AreaLevelRecord` offsets into typed `AreaLevel` pointers; `ReadObjectRecordField` in `src/Game/fieldobj.c` reads a 16- or 32-bit value from a byte buffer. | Treat the casts as file-format boundaries until all offset and width interpretations are proved. Do not substitute an in-memory layout for packed data. |
| NPC palette input | `src/Game/treasurebox.c` passes a packed record's palette words to `LoadNpcPalette` through `u16*`; `src/Game/clock.c` passes a map record cell to `AddAreaNpc` through `u8*`. | Prove the source record format and alignment before replacing the byte or word views with a shared typed record. |
| Per-kind item parameters | `ItemRecord.params` in `include/Game/ItemRecord.h` remains a byte array. `DecodeItemRecord` writes different offsets for weapons, guns, gems and other kinds. Consumers with established meanings now use named accessors. | Recover each kind's complete variant layout and whole-object use before replacing the array with a union or separate record types. |
| Header ownership | `include/Platform/GameCalls.h` collects game declarations needed by the Windows layer, including `RedrawFieldAt`, texture helpers and `ClearHandleTable`; moving a declaration into an owner header changes MSVC 5 translation-unit state. `include/Platform/WinMain.h` still marks `g_windowRect` as a placeholder extern. | Move each declaration when the owner and original include boundary are evidenced, then compile every affected unit and compare functions and referents. |
| Incomplete device and NPC records | `D3DDeviceInfo` in `include/Platform/D3DApp.h` retains `reserved1[0x38]` and `reserved2[0x1b4]`; `AreaNpc` in `include/Game/AreaNpc.h` retains an unresolved `pad00[0x14]`. Its drawing callee reads only `textureSlot` through the complete record pointer. | Name fields only after callers, storage, and whole-record access establish their roles. Size and offset alone do not establish identity. |
| Direct3D COM and fog states | `src/Platform/d3dapp.cpp` passes interface output addresses as `void**` to `QueryInterface` and sends the bit pattern of `fogStart` and `fogEnd` through `SetLightState(DWORD)`. | The SDK signatures require these representations. A typed Direct3D helper must preserve the interface output write and exact float bits, as well as its caller code. |
| Registry record bytes | `src/Platform/devicesettings.cpp` gives `DeviceSettings*` to `RegQueryValueEx` as `BYTE*`. | The Win32 API writes a complete binary record through its byte buffer parameter. Preserve the record's exact size and layout before introducing a typed wrapper. |
| BMP palette and packed image walking | `src/Gfx/bitmapio.cpp` views `RGBQUAD` and `PALETTEENTRY` arrays as four-byte `DWORD` words in `ConvertBitmapPalette`; its DirectDraw call views a BMP record as `BITMAPINFO`. `src/Gfx/layertexture.cpp` advances packed BMPs using a `bfSize` cached before the texture-loader call. | Prove the palette layout and alias-safe typed access before changing the word views. Replacing the cached-size walks with `GetNextBitmap` rereads `bfSize` after the loader and changes both previously exact functions, so retain the explicit byte arithmetic until an equivalent helper is recovered. |
| MIDI stream and WinMM | `src/Sound/midistream.cpp` views `MIDIHDR.lpData` as `DWORD*` for event words, advances MIDS and prepared stream buffers by serialized byte sizes, and passes callback/user pointers through WinMM's `DWORD` slots. `include/Sound/MidiStream.h` converts a stream handle to `HMIDIOUT` for the output calls. | Preserve the 32-bit callback ABI, buffer alignment and variable-length record extents. The output handle types are distinct SDK declarations; a same-address value does not establish a typed conversion. |
| Panel command dispatch | `src/Text/font.cpp` stores three no-argument functions in the same `void (*)(i16)` table as commands that receive a character. | Recover a typed variant table or wrappers only with evidence for the table's retail referents and the caller's stack cleanup. The uniform dispatch currently passes the character to every slot. |
| Shift-JIS text bytes | `src/Text/font.cpp` accepts public strings as `const char*` but `ReadTextChar` decodes unsigned bytes; `ReadStringTextChar` holds that conversion at the decoder boundary. | Preserve the public string and CRT API types. A single cast at the byte decoder is the supported boundary until a shared text view is recovered from every caller. |
| Late-bound IME callback | `include/Platform/Ime.h` turns `GetProcAddress`'s `FARPROC` into the `WinnlsEnableImeProc` signature. | The API supplies no stronger function-pointer type; keep the boundary until the Windows export signature and calling convention can be expressed without changing the late-bound call. |

`giten verify casts` now finds 48 `reinterpret_cast` sites, all explained by
the boundaries above or by the source-side comments at their call sites. The
MIDI byte-count subtraction in `CMidiStream::ConvertBuffer` uses one cast to
`char*`, then subtracts `MIDIHDR.lpData` directly; that second operand is
already `char*`, and the MSVC object stayed byte-identical. The BMP
byte-walking macros in `include/Gfx/Bitmap.h` and MIDI event-buffer walking in
`include/Sound/MidiStream.h` retain casts because their offsets come from
serialized sizes. A textual cast count is not proof of a better source model.

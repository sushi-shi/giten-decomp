# Giten

Binary-matching reconstruction of **Giten Megami Tensei: Tokyo Mokushiroku**
(偽典・女神転生 東京黙示録; ASCII / Yū-Kikaku), the 1999 Windows `DDS.EXE`.
The build compares reconstructed C and platform C++ with retail using MSVC 5.0 SP3.
`giten play` builds a playable image with retail bug fixes and starts it under Wine;
see [Playing](docs/play.md).

## Quickstart

Use x86_64 Linux with [Nix](https://nixos.org/download) and flakes enabled.
Supply your own retail executable at `build/local/DDS.EXE` and toolchain at
`build/local/toolchain/`, or set `GITEN_RETAIL_EXE` and `GITEN_TOOLCHAIN` to
their local paths. The toolchain layout is `msvc/{bin,include,lib}`,
`dx/{Include,Lib}`, and `ninja/ninja.exe`; these inputs stay outside Git.

```sh
nix develop                 # initializes the build Wine prefix
export GITEN_DIR=$PWD       # select this worktree
giten build                # compile and compare all units
giten match range          # iterate on one unit
giten verify status        # inspect scores
giten build verify         # merge checks
```

Read [AGENTS.md](AGENTS.md) for reconstruction rules and the
[documentation index](docs/README.md) for build, data, and compiler references.
Use `giten --help` for commands. [clangd setup](docs/clangd.md) provides editor navigation.
